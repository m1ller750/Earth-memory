# Demo accounts (local development only)

Created by the seed when `NODE_ENV` is not `production`, or when `DEMO_PASSWORD` is set explicitly.
All share the password `earth-memory-demo` (override with `DEMO_PASSWORD`). **Never use these in production.**

| Email | Role | Use it to try |
|---|---|---|
| admin@earthmemory.local | Administrator | Everything, including moderation |
| moderator@earthmemory.local | Moderator | Reports and restricting records (`/moderation`) |
| expert@earthmemory.local | Expert | Expert verification, accepting or rejecting engine links (`/review`) |
| steward@earthmemory.local | Contributor and steward of the fictional Demo Highland Community | Reading and publishing community-restricted records |
| contributor@earthmemory.local | Contributor | Contributing, community review, API keys |
